# Evidencia visual

Capturas reales del build local contra el stack Supabase local, con los datos
de **demostración** de `npm run seed:demo` (por eso la franja verde superior).
El conjunto completo (245 capturas en 7 anchos y su informe JSON) se genera con
`npm run audit:visual` en `evidence/visual/` (no se versiona).

| Archivo | Qué muestra |
| --- | --- |
| `comparacion-*.png` | Referencia de diseño (izquierda) y la implementación a 390 px (derecha): inicio, explorar, tienda, producto, ferias, carrito, panel del artesano, panel del organizador y comunidad fundadora |
| `390-*.png` | Pantallas de panel, seguimiento, feria y estados vacíos en teléfono |
| `320-inicio.png`, `430-producto.png`, `768-inicio.png` | Anchos extremos y tableta |
| `1280-*.png`, `1440-*.png` | Escritorio: inicio, tienda, panel, ferias y administración |
| `e2e-*.png` | Momentos de los recorridos E2E: checkout con retiro en feria, pedido enviado, lista de pasos del alta, pedido nuevo en el panel, aprobación en administración, inscripción confirmada y página pública de la feria |
| `sofia-escenas.png` | Las 9 escenas del personaje |
